核心思想：g1_api 是唯一入口。它对外提供思岚(Slamtec)风格 REST API（端口 1448），对内编排三条通道——ROS1 导航栈、Unitree DDS 服务、外部动作执行器。所有客户端（浏览器 /sdk、你的 Python 程序、导览逻辑）都只和它说话。

01代码地图与分层规则

仓库 g1_api/ 是严格分层的 Python 包（3.8 语法），分层由测试强制（layering test 会拒绝违规 import）。

层目录职责规则
模型g1_api/models/纯数据结构与纯逻辑：动作参数、地图包(.g1map)、航迹点、外部动作元数据、互锁枚举models/core/state/adapters/services/tour 禁止 import fastapi/pydantic/网络客户端（utils 与 adapters 豁免）
核心g1_api/core/RobotCore：时钟、事件总线、安全门、动作注册表、任务管理器（动作槽）
适配器g1_api/adapters/mock/ 全功能仿真世界（202+ 测试的地基）；g1/ 真机：RosBridge(rospy)、DdsBridge(unitree_sdk2py，可打桩 stub)、LaunchManager(roslaunch 子进程)
服务g1_api/services/用例逻辑：每个动词先过安全门再调 adapter（map/motion/voice/arm/hand/external_actions/tour_service…）
网关g1_api/gateway/FastAPI 路由（薄）：解 JSON → 调 service → problem+json 错误
导览g1_api/tour/TourExecutor 状态机——吃自己的狗粮：每条腿走内部动作 API，不直捅 adapter

请求生命线：HTTP → gateway 路由 → service.guard(安全门) → adapter(mock 或 g1) → 硬件/仿真。mock 与真机共享全部上层代码——所以仿真验证过的逻辑真机同构。

02动作系统：思岚异步模型

所有"让机器人动"的请求都是动作：提交即返回，轮询看进度。全局单槽——同一时刻只有一个运动动作在跑，新动作顶替旧动作。

# 提交（立即返回 action_id）
POST /api/core/motion/v1/actions
{"action_name": "slamtec.agent.actions.MoveToAction",
 "options": {"target": {"x": 1.0, "y": 0.5}, "yaw": 0.0, "with_yaw": true,
             "reach_threshold": 0.35, "yaw_threshold": 0.5, "timeout_s": 180}}

# 轮询（:current 或 /{action_id}）；DELETE :current = 取消
GET /api/core/motion/v1/actions/:current
→ {"state": {"status": 1, "result": 0, "reason": ""}}
字段取值语义
state.status0 / 1 / 4排队 / 执行中 / 终态
state.result0 / -1 / -2成功 / 失败 / 被取消（仅终态有意义）
failure_codeTIMEOUT · GOAL_UNREACHABLE · CANCELLED_BY_USER…失败分类
GET :current → 404404 = 空闲，是正常语义不是错误（思岚约定）

MoveTo 全链路（aero 分层到点）

第0层 预转向
调 /move_base/make_plan 只算不走，取全局路径前 0.5m 方向；与当前朝向差 >57° 就原地慢转到 <23° 再出发
第1层 位置=planner 说了算
发布目标；TEB yaw 容差=2π（不管朝向），xy 进 0.35 圈立即 SUCCEEDED；消费 /move_base/result
第2层 朝向收口
with_yaw=true 时原地慢转(0.41 rad/s)到 yaw_threshold（默认 0.5≈±28.6°）内
  • planner ABORTED（如"Robot is oscillating"）→ 动作失败，planner 原因原文透传到 reason。
  • TF 只做事后复核；位置超出 reach_threshold 才触发兜底细调（只收到 reach_threshold，不过度矫正）。
  • 其余动作：MoveAction（定时定速遥控，不避障，受 ALLOW_MOTION 独立开关）、Rotate/RotateTo（原地转）。工厂列表见 GET /action-factories。
容差三层

① TEB xy_goal_tolerance=0.35（planner 宣告半径，yaml）② API reach_threshold=0.35/yaw_threshold=0.5（校验与收口，默认值，可每请求/每航迹点覆盖）③ 想要"正对展品"就把该点 yaw_threshold 单独收到 0.15。

03地图 · 建图 · 定位

建图会话（/mapping，四端点状态机）

POST /api/core/slam/v1/mapping/:start    # 停导航栈 → 起 FAST-LIO 建图栈
GET  /api/core/slam/v1/mapping           # 会话状态
POST /api/core/slam/v1/mapping/:finish   {"map_id":"changdi-1f","name":"场地一层"}
POST /api/core/slam/v1/mapping/:cancel   # 放弃，产物不入库

:finish 自动：存 2D 栅格 → 停栈存点云 → 校验产物新鲜度 → 打包 .g1map 入库 → 停掉建图 ROS 进程（后台保持干净）。建图期间 mapping_running 互锁挡导航/导览，遥控(MOTION)保留用于驱动扫图。

.g1map 包与地图库

.g1map = tar.gz（map.pcd 3D 点云 + ground_map.pcd + grid.pgm/yaml 2D 栅格 + manifest.json 含航迹点 + checksums）。库在 g1_api_maps/（挂载卷持久）。上传/下载/删除见附录端点表；栅格可在线改（GET/PUT /{id}/grid，编辑器画墙擦墙就是这两条）。

:select 与重定位（服务重启后的必经两步）

POST /maps/{id}/:select        # 停旧导航栈 → 以该图三个文件为参数重启导航 launch
                               # 就绪门：/slam_reloc 服务 + move_base 注册（TCP 实测，防僵尸）
POST /localization/:relocalize {"x":0,"y":0,"yaw":0}   # 机器人须物理摆在地标位
GET  /localization/pose        # TF map→body 的实时位姿

TF 链：map → local →（FAST-LIO 定位）→ body →（静态 π 翻转）→ base_link。重定位是 ICP 配准（/slam_reloc 服务），朝向大致对齐即可收敛（实测 4cm 级）。

04导览编排

航迹点随地图保存（manifest 里），编辑器点选配置。导览执行器逐点：MoveTo（分层到点）→ 并行【动作序列 + TTS】→ 停留 → 下一点。

PUT  /api/core/slam/v1/maps/{id}/tour-points   # 写航迹点（编辑器自动调）
{"points": [{"name":"P1","x":0.5,"y":0,"yaw":0,
  "actions":[{"executor":"onboard","type":"arm","id":26},
             {"executor":"external","type":"replay","id":"pick-cube"}],
  "tts_text":"Welcome.","dwell_s":1.0,
  "reach_threshold":0.35,"yaw_threshold":0.5}]}

POST /api/tour/v1/tours/:start | :pause | :resume | :stop
GET  /api/tour/v1/tours/:current     # 每点 pending/succeeded/failed/skipped
  • 每点动作二選一执行器：onboard（官方手臂 id / 灵巧手 cmd，过安全门）；external（回放库 id 或自定义类型，见 06）。
  • 失败策略 on_failure：abort（默认）/ skip / retry_once。外部动作失败永不中断导览（只记事件）。
  • 导览运行中 tour_running 互锁挡手动运动指令——但导览自己的腿不受限（内部把该互锁豁免）。

06外部动作：回放库

把录制的双臂关节轨迹（.npy，N×≥14 @录制频率）当官方动作用：上传入库 → 列表 → 按 id 执行。g1_api 只当图书馆+调度；真正驱动的是 g1_replay_min/action_server.py（:9100，走 rt/arm_sdk：29 号权重位接管双臂、腿仍归运控、结束权重缓降交还——与行走控制天然共存）。

# 上传（body=.npy 原始字节；frequency 必须=录制频率；query 仅 ASCII——网页 /sdk 上传无此限制）
POST /api/core/motion/v1/external-actions?name=pick-cube&frequency=30&velocity_limit=20
GET  /api/core/motion/v1/external-actions            # 库列表（id/帧数/时长）
POST /api/core/motion/v1/external-actions/{id}/:execute   # 同步：返回=回放结束
DELETE /api/core/motion/v1/external-actions/{id}
  • 执行期挂 external_motion_running 互锁：官方手臂/导航/导览启动 409；MOTION 遥控保留逃生。执行器单飞（忙 409）。
  • g1_api → 执行器契约：POST {"action": {"type":"replay","id","file","frequency","velocity_limit","duration_s",…}}，超时=时长+30s。
  • 导览引用：{"executor":"external","type":"replay","id":"x"}（编辑器下拉直接选）；type 本身是库 id 也认。不在库里的自定义类型原样透传——这是接你自己的执行器的缝。

07安全系统

每个状态改变请求过安全门：先查能力开关（环境变量，默认全关），再查命名互锁。拒绝=409 + problem-json，body 里带互锁名清单——排障永远先看它。

能力开关（G1_API_SAFETY_ALLOW_*，默认 false）

MOTION（不避障遥控，日常不开）· NAVIGATION · MAP_WRITE · ARM · HAND · VOICE · TOUR。急停类停止命令永远放行，任何开关拦不住。

命名互锁（状态类）

互锁亮起原因挡什么
roscore_down / move_base_downROS 侧没起/僵死（TCP 实测）导航类
velocity_bridge_down速度桥进程死了一切会动的
map_not_selected / localization_not_initialized没 :select / 没重定位导航、导览
tour_running导览进行中手动运动/臂/手（导览自身豁免）
mapping_running建图会话中导航、导览（遥控保留）
external_motion_running回放执行中官方手臂、导航、导览启动

速度钳制：MoveAction 的线/角速度超 SafetyConfig 上限会被钳制并标注。全部决策带 command_id 审计日志。

11Python 调用实战

可运行完整版在仓库 docs/examples/g1_client_demo.py（仅依赖 requests）。下面按场景拆讲。

骨架：一个 50 行的客户端

import requests, time

class G1Client:
    def __init__(self, base="http://192.168.220.8:1448"):
        self.base = base.rstrip("/"); self.s = requests.Session()

    def submit_action(self, name, options):
        r = self.s.post(self.base + "/api/core/motion/v1/actions",
                        json={"action_name": name, "options": options}, timeout=10)
        r.raise_for_status()
        return r.json()["action_id"]

    def wait_action(self, aid, timeout_s=180):
        deadline = time.monotonic() + timeout_s
        while time.monotonic() < deadline:
            r = self.s.get(self.base + "/api/core/motion/v1/actions/%s" % aid, timeout=10)
            st = r.json()["state"]
            if st["status"] == 4:          # 终态：result 0/-1/-2
                return r.json()
            time.sleep(0.5)
        self.s.delete(self.base + "/api/core/motion/v1/actions/:current", timeout=10)
        raise TimeoutError(aid)

外部程序四条纪律

① 动作是异步的：永远轮询到终态再发下一个（单槽，新动作会顶掉旧的）。② 409 不是 bug，是安全门在说话——读互锁名。③ 运动指令单一来源：你的程序在跑就别同时用 RViz/网页发目标。④ 长超时给足：:select 要重启导航栈（~90s 门限），外部动作=轨迹时长+30s。
